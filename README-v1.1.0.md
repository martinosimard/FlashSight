# FlashSight Reader App v1.1.0 - Guide des Nouvelles Fonctionnalités

## 🚀 Visualiseur PDF Intégré

### Fonctionnalités principales
- **FlashSight pour PDFs** : Transformation bionique du texte directement dans les documents PDF
- **Thèmes adaptatifs** : Mode clair/sombre avec synchronisation automatique
- **Contrôles avancés** :
  - Navigation par pages (←/→ ou boutons)
  - Zoom personnalisable (50% - 300%)
  - Ajustement de la taille de police (12px - 24px)
  - Scrollbar personnalisée avec indicateur de progression

### Utilisation
1. Ouvrez un PDF via le bouton "📄 Ouvrir PDF" ou glissez-déposez un fichier
2. Utilisez la barre d'outils pour :
   - Naviguer entre les pages
   - Ajuster le zoom et la police
   - Basculer entre thème clair/sombre
   - Activer/désactiver FlashSight

### Raccourcis clavier
- `←` / `→` : Page précédente/suivante
- `+` / `-` : Zoom avant/arrière
- `0` : Ajuster à la largeur
- `Ctrl+D` : Télécharger le PDF

## 🆘 Résolution de Problèmes

### PDF ne s'affiche pas
- Vérifiez que le fichier n'est pas corrompu
- Essayez de redémarrer l'application
- Consultez la console développeur (F12)

### Dropdown historique invisible
- Cliquez directement dans la barre d'URL
- Vérifiez que vous avez visité des pages
- Redémarrez l'application si nécessaire

### Thème ne s'applique pas
- Vérifiez les paramètres dans le panneau latéral
- Basculez entre thèmes pour forcer l'application
- Vérifiez la synchronisation avec les préférences système
